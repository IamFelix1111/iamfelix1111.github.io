Recording

A zero-dependency native Win32 screen recorder for Windows: DXGI Desktop Duplication capture with automatic GDI fallback, Media Foundation H.264 encoding to MP4 — a single static-linked exe with no installer and no extra DLLs.

No stable release yet.

Latest pre-release: v0.2.0-test.

Features

  • Capture: DXGI Desktop Duplication (GPU path) with automatic GDI fallback; record a single monitor or, on the GDI backend, the whole virtual desktop.
  • Encoding: Media Foundation H.264 → MP4, with hardware encoding used automatically when available.
  • Mouse pointer: composited into the video (per-pixel alpha blending on the DXGI path) and can be disabled.
  • Recording border: a red frame marks the capture area (yellow while paused) — always on top, click-through, and never captured into the video.
  • System tray: click to pause/resume, double-click to show the window, middle-click to stop; while recording, closing the window just hides it to the tray.
  • Live stats: state, duration, fps and file size update in real time, mirrored in the title bar with a status-colored icon.
  • Path templates: output paths support known-folder tokens (CAPTURES, VIDEOS, …) and date-time tokens (YYYY/MM/DD/HH/MM/SS).
  • Settings memory: every option is saved instantly and restored on restart; missing output folders are created automatically.

Usage

  • Pick the monitor, frame rate (10–60), bitrate (auto or 4–40 Mbps), output path, cursor visibility and capture backend.
  • Press Start (the default button — Enter works). Pause/Resume at any time; the same button becomes Stop and reports a successful save.
  • By default recordings go to the Captures folder as Capture-YYYYMMDD-HHMMSS.mp4.
  • While recording you can minimize or close the main window — keep controlling everything from the tray icon.

Requirements

  • Windows 10 2004 or newer (recommended — excluding the border from capture needs 2004).
  • A graphics device with DirectX 11 support.
  • Nothing else: everything is statically linked into the single RecordingGui.exe.
